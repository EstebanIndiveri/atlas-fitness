# Components

UI reutilizable por dominio.

## Estructura

- `ui/` — componentes base reutilizables (botones, inputs, cards, etc.)
- `workout/` — componentes de entrenamiento (cuando se implementen)
- `exercises/` — componentes de ejercicios (cuando se implementen)
- `auth/` — componentes de autenticación (cuando se implementen)

## Guías

- Ver `AGENTS.md` §§8–10
- Ver `docs/engineering/conventions-fe.md`
- Mobile-first
- Un concern por componente
- Extraer hooks a `hooks/` cuando la lógica no sea solo UI
