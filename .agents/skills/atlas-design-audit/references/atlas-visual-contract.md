# Atlas Visual Contract

## Thesis

Atlas uses "calma atlética":

A warm and human baseline, precise presentation of data, and brief
energy only around verified events.

The UI should feel:

- calm
- deliberate
- athletic
- trustworthy
- useful during an actual workout
- data-aware without becoming an analytics dashboard

It should NOT feel:

- generic SaaS
- crypto dashboard
- bodybuilding extreme
- medical/clinical
- childish gamification
- neon gaming
- AI-purple product
- animation showcase

# Semantic hierarchy

## Action

Brand color represents action and orientation.

It does not mean "everything positive".

## Verified

Verified progression has its own semantic role.

A verified event must be backed by Atlas domain truth.

## Unknown

Insufficient evidence must remain visibly unknown.

Never convert unknown into:

- zero
- failure
- negative progress
- success

## Warning / danger

Reserved for actual risk/error semantics.

Never use simply for visual emphasis.

# Surfaces

L0 Canvas

- page/base

L1 Panel

- grouped content
- generally flat
- subtle boundary

L2 Overlay / Hero

- temporary elevation
- focused content
- hero moments

Avoid nested elevated cards without semantic reason.

# Shape

control = normal controls

panel = grouped surfaces

hero = major focal surfaces

pill = tags, status chips, circles only

Do not create arbitrary radius values when a role exists.

# Typography

display

- editorial moments
- hero/chapter heading
- never forms or dense data

heading

- page and section hierarchy

body

- normal UI copy

caption

- supporting copy

numeric

- comparable data
- tabular figures

# Motion

Motion must have purpose.

Allowed purposes:

- orientation
- continuity
- confirmation
- progress
- celebration
- actionable attention
- waiting
- error recovery

No perpetual attention motion.

No motion that implies a domain fact.

No replaying progress from zero on every visit.

No shake for errors.

No confetti for ordinary actions.

Reduced motion must preserve comprehension.

# Mobile

390px is a first-class design target.

Check:

- wrapping
- touch targets
- safe areas
- keyboard
- long Spanish copy
- data widths
- zoom
- sticky/fixed controls
